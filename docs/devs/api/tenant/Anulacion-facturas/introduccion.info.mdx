La API del **Facturador** permite emitir comprobantes de pago electrónicos (CPE) y
obtener por cada uno los 3 archivos indispensables: **XML Firmado, PDF y CDR**.

Documentos contemplados:

1. Factura
2. Boleta
3. Nota de Crédito
4. Nota de Débito
5. Resúmenes diarios (boletas)
6. Anulaciones (comunicación de baja)
7. Guía de remisión (remitente y transportista)
8. Cotización
9. Inventarios
10. Productos

**Autenticación:** todas las peticiones requieren el token de la cuenta enviado en el
encabezado `Authorization: Bearer <TOKEN>` junto con `Accept: application/json`.
El token se obtiene en el módulo **Configuración → Usuarios** del sistema (columna
"Api Token") o mediante `POST /api/login` con el correo y contraseña del usuario.
